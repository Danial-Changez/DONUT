## Why DONUT

- **One list, whole fleet** — add machines by name or from the live Active Directory
  finder, then scan or apply Dell updates on all of them in parallel.
- **See everything** — each machine gets a live status row and a detail pane with its
  inventory, available updates, and biggest-folders storage scan.
- **People too** — search a person to open their Lens: directory facts, their devices,
  and BitLocker recovery keys, fetched safely de-elevated.
- **Stays out of the way** — tray icon, global hotkey, start-with-Windows, and
  self-updates from GitHub releases.
